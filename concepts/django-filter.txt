# 🔹 What is **Django Filter Backend**?

The **Django Filter Backend** (`django-filter`) is an **add-on library** for Django REST Framework (DRF) that lets you easily **filter querysets** based on URL query parameters.

Example:

```http
GET /products/?category=books&min_price=100&max_price=500
```

Instead of writing manual filtering logic in `get_queryset()`, `django-filter` automatically applies filters based on the query parameters.

---

# 🔹 How it works

1. You install and enable the **DjangoFilterBackend** in DRF’s settings.
2. You define a `FilterSet` (like a serializer, but for filtering).
3. DRF will automatically read query parameters (`?field=value`) and apply them to your queryset.

---

# 🔹 Setup & Example

### 1. Install

```bash
pip install django-filter
```

### 2. Add to settings

```python
REST_FRAMEWORK = {
    'DEFAULT_FILTER_BACKENDS': [
        'django_filters.rest_framework.DjangoFilterBackend'
    ]
}
```

### 3. Define a FilterSet

```python
import django_filters
from .models import Product

class ProductFilter(django_filters.FilterSet):
    min_price = django_filters.NumberFilter(field_name="price", lookup_expr="gte")
    max_price = django_filters.NumberFilter(field_name="price", lookup_expr="lte")
    category = django_filters.CharFilter(field_name="category__name", lookup_expr="icontains")

    class Meta:
        model = Product
        fields = ['category', 'min_price', 'max_price']
```

### 4. Use in a View

```python
from rest_framework import generics
from django_filters.rest_framework import DjangoFilterBackend
from .models import Product
from .serializers import ProductSerializer
from .filters import ProductFilter

class ProductListApiView(generics.ListAPIView):
    queryset = Product.objects.all()
    serializer_class = ProductSerializer
    filter_backends = [DjangoFilterBackend]
    filterset_class = ProductFilter
```

### 5. Usage

Now you can hit URLs like:

```
/products/?min_price=100&max_price=500&category=electronics
```

and DRF will automatically filter results.

---

# 🔹 Benefits of Django Filter Backend

✅ **No boilerplate filtering code** → you don’t need to manually override `get_queryset()` every time.
✅ **Powerful filtering** → supports exact matches, ranges (`gte`, `lte`), text search (`icontains`), multiple values, etc.
✅ **Declarative** → you just declare filters in a `FilterSet` class (clean & maintainable).
✅ **Automatic integration with DRF browsable API & drf-spectacular** → query params appear in Swagger UI docs.
✅ **Reusable** → FilterSets can be shared across multiple views.

### ⚖️ Without DjangoFilterBackend:

```python
def get_queryset(self):
    qs = Product.objects.all()
    min_price = self.request.query_params.get('min_price')
    if min_price:
        qs = qs.filter(price__gte=min_price)
    max_price = self.request.query_params.get('max_price')
    if max_price:
        qs = qs.filter(price__lte=max_price)
    return qs
```

### ✅ With DjangoFilterBackend:

```python
class ProductListApiView(generics.ListAPIView):
    queryset = Product.objects.all()
    serializer_class = ProductSerializer
    filterset_class = ProductFilter
```

Much cleaner 🚀
